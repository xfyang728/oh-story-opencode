## 判定优先级（先读这一节）

判定顺序固定，不得跳级：

1. **作者基线**（权威来源：`{对标书路径}/文风.md` 的「作者指纹词（正向白名单）」或自定义 `设定/文风.md`）
   ——某个词落在白名单频次带内时，**该词不再算 AI 味**，照常写。
2. **组合级高危**（本文件「组合级禁用」小节）
   ——**任何情况下都不得用作者基线豁免**。哪怕作者原文出现过同词，组合形态一律改。
3. **单字级**
   ——默认清扫；仅在第 1 条命中时豁免。

> **为什么要有第 1 条**：禁用词表是普适统计，作者是具体的人。实测某书作者高频使用
> `猛的／亦是／皆是／有着／一旁／微微／一丝／忽然／瞬间`——正是本表一级词。全量净化后
> 统计上"更干净"，听感上却"不像这本书"。**仿写类任务的最高目标是像作者，不是像模板。**

**白名单如何写**：`文风.md` 的指纹词表须带每万字频次带（如 `微微 4-7`）。
命中数落在带内 = 豁免；显著超出带上限（约 >2 倍）仍按单字级处理。无 `文风.md` 时本条整体跳过，
按原策略执行（不装文风的短篇行为不变）。

---

## 组合级禁用（blocking，作者基线不可豁免）

**判定单位是组合，不是单词。** 单词是作者可能有的口癖，组合才是 AI 的指纹。

| 毒级 | 组合 | 错误例 | 修法 |
|------|------|--------|------|
| ★★★★★ | "不是A，（而）是B" / "不是A，不是B，（而）是C"（"而"可省略，省掉也算命中）| "他不是冷漠，而是绝望" | 直接写 B 或用更自然的表达 |
| ★★★★★ | "没有X，没有Y，（只是）Z" 排比否定 | "没有犹豫，没有恐惧，只有麻木" | 拆开，或只留一条 |
| ★★★★ | "，带着……" 万能状语 | "他笑了一下，带着一丝不易察觉的嘲讽" | 拆短句或换动作 |
| ★★★★ | "声音不大，却带着一种……的力量" | "她声音不大，却带着不容置疑的力量" | 直接写声音特征或动作 |
| ★★★★ | "他/她知道……"（叙述者代言认知） | "他知道这一切都来不及了" | 用行为展示认知 |
| ★★★ | "仿佛/犹如/宛若……一般" | "仿佛能穿透一切一般" | 删掉或白描 |
| ★★★ | "眼中闪过一丝……" / "嘴角勾起一抹……" | "眼中闪过一丝悲伤" | 他垂下眼 / 他笑了一下，没到眼底 |
| ★★★ | "心中涌起一股……" / "心头一震" / "不由/不禁+身体反应" | "心中涌起一股暖流" | 用身体反应 |
| ★★ | 章末预告 "他不知道的是……" | "他不知道的是，更大的风暴即将来临" | 用具体钩子物件/事件收束，避免空泛预告 |
| ★★ | 叙述里短词加引号强调 | 他是被请来"把关"的 | 去掉引号，或改成具体动作 |

> 凡命中 ★★★★★ 一处即视为重度AI味的强证据；★★★★ 命中 ≥2 处即触发中度复扫。
> 本节不含任何单字词，因此**不存在"作者爱这么写"的辩解空间**。

## 单字级禁用（advisory，可被作者基线豁免）

以下都是**词**。仿写/续写任务里先查 `文风.md` 白名单：带内即豁免，带外照删。

### 情态类
仿佛、犹如、宛若、如同、一丝、一抹、些许、几分、隐约

### 动作类
深吸一口气、缓缓、不禁、微微、轻轻、淡淡

### 表情类
眼中闪过、嘴角勾起、眉头微皱、眉眼低垂、瞳孔微缩

### 心理类
心中一动、心头一震、心下了然、心中暗道、心底泛起、不由得

### 判断类
不容置疑、不容置喙、不易察觉、显而易见、毫无疑问、不可否认

### 形容类
坚定、闪烁着光芒、狡黠、深邃、凛冽、冰冷

### 过渡类
不由自主、情不自禁、自然而然

> 上列中 `眼中闪过`／`嘴角勾起`／`心中一动` 等亦可作为组合的一部分被更早捕获；
> 组合级优先，命中组合就走组合级修法，不走豁免。

## 二级禁用词（高频出现时替换）

### 语境敏感词（仅高频或偷懒时处理）
突然、好像、瞬间（角色口语、真实突发、时间压缩、视角不确定时可保留）

### 书面腔 → 口语化

| 书面腔 | 口语化替换 |
|--------|-----------|
| 瓦解 | 消失 / 散了 / 没了 |
| 无名火 | 烦躁 |
| 往我心上捅刀子 | 心烦意乱 |

### 总结句式
- "他/她终于明白..."
- "他/她这才意识到..."
- "此刻，他/她..."
- "一切...都..."
- "原来..."

### 排比句式
- 连续3句以上相同结构的排比
- "有的...有的...有的..."
- "一边...一边...一边..."

### 升华句式
- "这一刻..."
- "他知道..."
- "她明白..."
- "这就是..."

## 禁用句式模板

| 句式 | 示例 | 问题 | 判定级 |
|------|------|------|--------|
| "不是A，而是B" | "他不是冷漠，而是绝望" | 最毒；直接写 B | 组合级 |
| "...，带着..." | "他说，带着一丝无奈" | 万能状语 | 组合级 |
| "声音不大，却带着……" | "她声音不大，却带着不容置疑的力量" | AI 最爱声音描写 | 组合级 |
| "仿佛能...一般" | "仿佛能穿透一切一般" | 文言腔 | 组合级 |
| 对话标签密度过高/公式化标签 | "好的，他说道" | 普通"说"可保留；高频或公式化时处理 | 单字级 |
| "他/她感到..." | "她感到一丝失落" | 告诉而非展示 | 单字级 |
| "他/她意识到..." | "他意识到事情不对" | 直接告知 | 单字级 |
| "眼中闪过一丝XX" | "眼中闪过一丝悲伤" | 模板化 | 组合级 |
| "嘴角勾起一抹XX" | "嘴角勾起一抹冷笑" | 模板化 | 组合级 |
| "心中涌起一股XX" | "心中涌起一股暖流" | 模板化 | 组合级 |

## 比喻分类（默认全删）

带"像/如/仿佛/犹如/宛若"的比喻是 AI 写作的强信号。默认全删，分类只是用来识别：

| 比喻类别 | 例 |
|---------|----|
| 动物类 | "像一头被抛弃的野狗" |
| 物品/现象类 | "像一把刀" "脸色惨白得像这漫天的雪" |
| 状态类（陈词滥调） | "梨花带雨" "如沐春风" |
| 抽象类 | "像命运的齿轮" "像上辈子的尘埃" |
| 假设类 | "力道大得像是要把骨头捏碎" |

处理：把比喻改为直接描述／动词／名词／作用／结果／事实。例 "脸色惨白得像这漫天的雪" → "脸色惨白"。

> **例外（作者基线）**：`文风.md` 的原文锚点片段里出现的比喻形态，说明是该作者的有效手法，
> 属于"生活化、角色化比喻可保留"范畴（见 SKILL.md Gate B 的 deslop 原始策略）。
> 判定依据是**锚点里有原型**，不是"我觉得这个比喻挺好"。


## 禁止标点与字符（最高优先级）

### 破折号「——」
**默认**：正文中表示停顿、转折、解释的「——」不用，按语境替换：
| 语境 | 替换 |
|------|------|
| 短停顿 | 逗号「，」 |
| 长停顿 / 句意转折 | 句号「。」 |
| 解释说明 | 冒号「：」 |
| 话被打断 | 省略号「……」或直接断句 |

❌ 错误："他推开门——屋里空无一人。"
✅ 正确："他推开门。屋里空无一人。"

❌ 错误："她转身要走——突然停住了。"
✅ 正确："她转身要走，突然停住了。"

> **作者基线例外（重要）**：当 `文风.md` 的「写作指标带」记录了非零的 `dash_per_kilo` 或
> `ellipsis_per_kilo` 时，说明**该作者本人就用这两个标点**（实测某书 `——` 708 次、`……` 1582 次）。
> 此时照常写、按基线密度写。禁的是 **AI 味的机械用法**（每段都在飘、把"我……想……说"这种
> 抖成碎句），不是作者的语气武器。
> **判定口径**：看密度是否在基线带内 + 该处是否有语气功能（打断/迟疑/未尽）。
> 无 `文风.md` 或带内值本就是 0 时，维持上面的默认禁则。

### 双连字符「--」
**正文中不得出现「--」（ASCII em dash 替代写法）**。一律按上表替换为逗号/句号/冒号。
**本条无作者基线例外**——`--` 是输入法/追写产物，任何中文网文作者都不会主动这么写。


### 角引号「」
**默认**：对话和引用使用半角双引号 `""`（U+201C/U+201D），不使用角引号「」（U+300C/U+300D）。角引号在中文网文阅读体验中视觉辨识度低，且 AI 生成文本高频使用角引号替代正确双引号。

❌ 错误：「你来了。」
✅ 正确："你来了。"

> **引号体系以项目文风为准**：`文风.md`（或自定义 `设定/文风.md`）明确声明了引号体系时，
> **以声明为准**——声明"对话用弯引号 `“”`"就用 `“”`；未声明时才用上面的默认值。
> **禁止混用**：同一本书内不得一半角引号一半弯引号，这比选错体系更严重。
> 收尾脚本 `normalize-punctuation.js` 须按声明选 `--quote-mode`（见 `workflow-chapter.md` 确定性收尾），
> 不得用默认值硬刷；`--check` 模式应先报出混用，再决定刷哪一边。

## 替换策略速查

| 原文类型 | 替换方法 | 示例 |
|----------|----------|------|
| 抽象情绪词 | 具体动作 | "紧张" → "手在抖" |
| "感到XX" | 外化表现 | "感到愤怒" → "攥紧拳头" |
| 形容词堆砌 | 白描手法 | "美丽动人的笑容" → "她笑了" |
| 书面表达 | 口语化 | "不容置疑" → "就是" |
| 解释性描写 | 留白 | "他因为害怕而..." → "他退后一步" |
| 连续排比 | 保留最强一条 | 3 句排比留 1 句 |
| 总结升华句 | 直接删除 | "这一刻，她终于明白了..." → 删 |
| "不是A，而是B" | 直接写 B 或更自然的表达 | "他不是冷漠，而是绝望" → 直接写 B |
| 多余修饰（形容词/定语/量词/指示代词） | 删 | "白色的药片" → "药片"；"手里那截链子" → "链子"；"飞驰的汽车" → "车" |
| 破折号「——」 | 逗号/句号/冒号（作者基线非零时照基线写） | "他推开门——屋里空无一人" → "他推开门。屋里空无一人" |
| 双连字符「--」 | 逗号/句号/冒号（无例外） | 同上 |
| 角引号「」「」 | 半角双引号 ""（文风另有声明时从其声明） | 「你来了」→ "你来了" |

> **删词策略同样受作者基线约束**：本表的"多余修饰""删"是**普适**建议。当作者原文靠短段、
> 口语词和重复推进节奏时，把修饰删到只剩主谓宾会把节奏一起删掉。
> 判定标准是**成稿指标是否还在 `文风.md` 的带内**（见 `scripts/style-metrics.js`），
> 不是"字数是否更少"。
