# 定式场景模板（Style Set-Pieces）

> **何时加载**：Phase 3 设计章节、Phase 4 写前准备。整书进入新地图/新队伍/新规则密集期时优先加载。
> **产物**：不独立落盘，作为 `文风.md` 的配套手法库；对标书专属条目写进 `{对标书}/文风.md` 的「定式场景模板」段。

## 为什么需要这一层

`文风.md` 给的是**句长、标点、段落、词频**这类量化基线，解决"一句话像不像"。
但"一段戏像不像"是另一回事：同样的事件，作者会按某种固定节拍展开，而这些节拍在句长指标里看不见。

实测教训（同一本书 464-466 章）：作者用**三段连续的说明性块**交代新地图——

1. 一名 NPC（女主管阮玉）出场，用一段内心戏交代她的身份、地位与野心
2. 会面时由 NPC 自己报家门、递名片，顺手补出信息
3. 一名 NPC（风无忌）用一整段口述把新规则说完：**古星封印真意、只能用窍穴发力、隐藏身份、古玉钱、二十天+十天、穿梭舟五人组队**

而 AI 续写把同样功能拆成"分散的动作与打点"——**不是错，是没写成本书那种样子**。
量化指标全部合格，读起来仍"不像这本书"。

> **结论**：量化基线负责"别漂"，定式场景模板负责"像"。两者缺一不可。

## 通用定式清单（任何长篇都可先套这五类）

| 定式 | 功能 | 常见节拍序列 | 篇幅参考 |
|------|------|--------------|----------|
| **A 入新场第一眼** | 建立等级秩序 | 换视角看一眼 → 一笔环境地标 → 主角与多数人的位差（衣料/站位/说话声） → 一个具体的"被看轻"动作 | 600-900 字 |
| **B 开新地图/新规则** | 让读者懂规矩 | 甩出一个反常事实引起疑问 → NPC 用**大段说明**交代规则（允许连续单句成段，但每段只放一个信息点） → 主角用一句判断收束（"这规矩对别人是枷锁，对他却是利好"） | 900-1500 字 |
| **C 队伍汇合/朝会** | 交代阵营与位次 | 分档画面（谁和谁站一起） → 一名话事人点名 → 主角被单独拎出来 → 有人当场变色 | 500-800 字 |
| **D 强者立威** | 拉高天花板 | 不出手就压场（气息/光/旗倒） → 全场失声的具体反应 → 只存在三息 → 收势后点一个名字 | 400-700 字 |
| **E 闻讯反应** | 制造落差 | 消息传开 → 分层反应（高位者的判断/同辈的嘲讽/底层的亢奋） → 一条反向假信号 → 当事人一句短台词 | 400-600 字 |

## 本书（国术：每日结算）专用模板

### T1 入新场（营地/学府/宗门第一眼）
**锚点**：464 章前院与港口、465 章核心候场区、466 章营地降落
**节拍**：①远景一句定性（"巨大到无法用言语形容"）→ ②分区特写（修炼区/珍宝区/宿舍区，各一句）→ ③声音从天而降宣告规则 → ④众人抬头，主角**只扫自己要找的那一行**
**注意**：作者不写"主角心中震撼"，写**别人看呆**（"风无忌亦看呆了"），主角的反应是动作（往下看自己的排名）。

### T2 规则说明块（新地图规矩）
**锚点**：465 章风无忌讲古星
**节拍**：①抛反常（"一身修为统统会被封印"）→ ②主角追问三连（"为何""那去做什么""有大用？"）→ ③NPC 逐条给答案，每答一条带一个新钩子 → ④主角一句内心判断收尾
**关键**：**问答驱动**，不用叙述者一次性倾倒；每段只放一个信息点，允许连续单句成段。

### T3 排名/位次公示
**锚点**：466 章特训总榜
**节拍**：①榜单一万五千人 → ②先给顶端（复姓霸榜，一句"果然"）→ ③再找熟人（武天两千一百一十二）→ ④最后找自己（五千一百名）→ ⑤同队对比（四人四档、主角卡在五档门槛）→ ⑥旁人的微动作（摇扇的手一顿、女子挪开半步）
**关键**：**主角的位次永远放在最后揭**，且用旁人的身体动作替他难受。

### T4 强者初见
**锚点**：466 章领队女子出场、武天在飞舟上独自盘坐
**节拍**：①先写**别人的反应**（"咕噜"咽唾沫、古族子弟交头接耳）→ ②再给主角的异常生理反应 → ③主角自己警惕（"不对劲"）→ ④旁人补一句身份与忌惮 → ⑤不安排交手
**关键**：强者的压迫感由**旁观者的失态**承担，主角只负责"察觉不对"。

### T5 人情与交换
**锚点**：464 章李副府主的两句提醒、466 章顾长风认领五人
**节拍**：①对方先摆出姿态（笑/冷脸）→ ②递出一个**具体数字或条件** → ③主角短句应答 → ④对方点明代价归属（"谁挑的人，谁自己担着"）
**关键**：人情往来必须落到**可指认的数字或条件**，不写"两人心照不宣"。

## 抽取方法（story-long-analyze Stage 6 追加产出）

1. 从 `章节/第K章_摘要.md` 与原文采样中，识别**同类场景出现 ≥2 次**的场景名（新地图、队伍汇合、名次公示、强者出场、审讯、宴会……）。
2. 每类抽 2-3 处原文，**逐段标节拍**（用上面的编号法），不要写抽象评论。
3. 记录**篇幅配比**（各类拍点各占几段/几字）。
4. 记录**允许的说明段形态**：本书是否允许连续单句成段的说明块？每段放几个信息点？
5. 落进 `文风.md` 的「定式场景模板」段，每条带原文锚点行号。

## 与其它文件的边界

- **本文件不管量化**：句长/标点/段长/词频一律以 `文风.md` 的「写作指标带」为权威。
- **本文件不管情绪与节奏**：情绪链与爆发节奏以 `剧情/情绪模块.md`、`剧情/节奏.md` 为权威。
- **本文件与 `writing-craft.md` 的分工**：writing-craft 给通用技法（延迟揭示、镜头写作、五感），本文件给**这本书的具体节拍**。
